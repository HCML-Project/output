# Output

Generated outputs from the Demographic Bias in Face Recognition across Image Perturbations project.

## Structure

```
output/
├── fairness_report.csv            # Per-group fairness metrics across all perturbations
├── verification_report.csv        # Per-pair verification scores
├── features/                      # Extracted face embeddings (.npy)
│   ├── African/
│   │   └── <perturbation_name>/
│   │       ├── features_0.npy     # Embeddings for image set 0
│   │       ├── features_1.npy     # Embeddings for image set 1
│   │       ├── similarities.npy   # Cosine similarities between pairs
│   │       └── labels.npy         # Ground-truth match labels
│   ├── Asian/
│   ├── Caucasian/
│   └── Indian/
├── perturbation_examples/         # Visual examples of each perturbation (PDF + SVG)
└── plots/
    ├── <ethnicity>/               # Per-ethnicity score distribution plots
    │   └── <perturbation>/        # Score distributions per perturbation level
    ├── DoB/                       # Degree of Bias plots
    ├── EER/                       # Equal Error Rate plots
    ├── FDR/                       # False Detection Rate plots
    ├── FMR100/                    # False Match Rate @ 0.01 FAR plots
    ├── FMR1000/                   # False Match Rate @ 0.001 FAR plots
    ├── ZeroFMR/                   # Zero False Match Rate plots
    ├── det/                       # Detection Error Tradeoff curves
    └── roc/                       # Receiver Operating Characteristic curves
```

## Generation

All outputs are generated by running the pipeline from the main repository:

```bash
# Extract features (saves .npy files to output/features/)
python src/extract.py

# Run analysis and generate plots/reports
python src/analysis.py

# Generate perturbation visual examples (saves to output/perturbation_examples/)
python src/perturbation_examples.py
```

See the main repository README for full usage instructions.
